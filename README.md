# FlyBand V2 Beta

This build replaces the earlier toy version with a more serious browser-first house simulation.

## Included in this rebuild

- One continuous six-room 3D house with open doors and furniture
- Tom / Paul / Stuart / Ringo / John
- Smaller, more fly-like fly models; eye color is the identifier
- Better camera controls inside the sim canvas
- Autonomous needs and room choice
- Send selected flies to rooms with auto/custom durations
- Individual or multi-selection
- Dark room + persistent wasp behavior
- Swatter punishment
- Brain monitor (whole-brain proxy visualization)
- More stats
- MP3/WAV upload
- Visual note-board editor instead of typing note letters
- Local save / import / export

## Honest note

The brain monitor is a **whole-brain proxy visualization** driven by live behavior/state, not yet the full MaleCNS connectome renderer. It is designed as the UI slot where the connectome visualization gets swapped in later.

## Deploy

Upload/replace all files in the repo root and let GitHub Pages rebuild.
